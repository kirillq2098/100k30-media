# 100K30 Media

Public media storage for the 100K30 project.

Only publish-ready assets intended to be fetched by external APIs such as Meta/Instagram belong here.

## Public URL pattern

Files are publicly reachable over GitHub raw HTTPS:

`https://raw.githubusercontent.com/kirillq2098/100k30-media/main/<path>`

Example:

`https://raw.githubusercontent.com/kirillq2098/100k30-media/main/instagram/2026-10-02/post-001.png`

## Rules

- No secrets, tokens, private data, or internal project files.
- Only publish-ready media.
- Use stable paths; do not overwrite a file after a publication references it.
- Instagram assets use `instagram/YYYY-MM-DD/<stable-name>.<ext>`.
- The repository is intentionally public.
